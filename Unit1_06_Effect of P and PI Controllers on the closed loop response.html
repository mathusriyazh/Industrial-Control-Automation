1. Introduction to Feedback Control

In closed-loop industrial control systems, the controller compares the setpoint (SP) with the measured process variable (PV) to calculate an error signal $e(t) = SP - PV$. The control algorithm processes this error to drive the actuator and stabilize the process.

Core Objective: Understand how Proportional (P) and Proportional-Integral (PI) action alter transient behavior (rise time, overshoot, settling time) and steady-state offset in closed-loop systems.

2. Proportional (P) Controller

A Proportional Controller outputs an action directly proportional to the current error signal.

Control Equation:

$u(t) = K_p \cdot e(t) + u_0$

Where $K_p$ is Proportional Gain, $e(t)$ is Error, and $u_0$ is Controller Bias.
🚀

Speed & Rise Time

Increasing $K_p$ decreases rise time, making the process respond faster to setpoint changes.

⚠️

Steady-State Error

P controllers cannot eliminate offset. A sustained error is required to output continuous control effort.

🌊

Stability Limits

Excessively high $K_p$ increases overshoot and can cause process oscillations or instability.

3. Proportional-Integral (PI) Controller

A PI Controller combines proportional action with integral action. The integral term accumulates past error over time to force the steady-state error to zero.

Control Equation:

$u(t) = K_p \cdot e(t) + K_i \int_{0}^{t} e(\tau) d\tau$    or    $u(t) = K_p \left[ e(t) + \frac{1}{T_i} \int_{0}^{t} e(\tau) d\tau \right]$
🎯

Zero Offset

Integral action guarantees zero steady-state error for step changes in setpoint or load disturbances.

📈

Increased Overshoot

Adding integral action lowers overall stability margins, causing higher overshoot if $K_i$ is too high.

🐢

Phase Lag

Integral action introduces a $90^\circ$ phase lag, which slows down response recovery if not tuned properly.

6. Chapter Summary

  • P Controllers provide fast initial corrective action proportional to instantaneous error.
  • P Controllers always leave a persistent steady-state offset under constant load or step inputs.
  • PI Controllers eliminate steady-state offset completely via continuous error integration.
  • Integral action tends to increase maximum overshoot and settling time due to accumulated phase lag.
  • Tuning requires balancing $K_p$ for fast response speed and $K_i$ for offset removal without driving the loop into instability.
Student memory rule:

⚡ $K_p$ Boosts Speed & Cuts Error (Leaves Offset)
🎯 $K_i$ Kills Offset (Adds Overshoot & Lag)
