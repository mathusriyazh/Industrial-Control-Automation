Chapter 10: Position – Linear and Rotary Potentiometers

This chapter explores resistive feedback position transducers. Topics include operating principles, electrical voltage divider behavior, mechanical construction, industrial applications, loading error analysis, and numerical motor-interfacing problems for both Linear and Rotary Potentiometers.

1. Linear Displacement Potentiometer (Pot-Slider)

Industrial Hardware Image


Working Principle

A linear potentiometer converts rectilinear displacement into a proportional electrical voltage. It consists of a uniform resistive element (carbon film, conductive plastic, or wire-wound) of total length $L_T$ and total resistance $R_T$. A sliding contact (wiper) attached to a moving shaft divides the element into two variable resistances. Assuming an ideal high-impedance meter, output voltage $V_{out}$ varies linearly with wiper position $x$:

$$V_{out} = V_{in} \times \left( \frac{x}{L_T} \right)$$

2. Rotary Angular Potentiometer

Industrial Hardware Image


Working Principle

Rotary potentiometers measure angular position $\theta$ over a defined electrical travel range $\theta_T$ (typically $270^\circ$ for single-turn, or $3600^\circ$ for 10-turn precision units). The wiper arm rotates around a circular track. The output voltage is directly proportional to shaft rotation angle $\theta$:

$$V_{out} = V_{in} \times \left( \frac{\theta}{\theta_T} \right)$$

Loading Error Effect: When connected to a signal conditioner with input impedance $R_L$, non-linear loading error occurs if $R_L$ is not significantly larger than $R_T$ ($R_L \gg R_T$).

Practical Applications, Advantages & Disadvantages

Potentiometer Type Key Applications Advantages Disadvantages
Linear Potentiometer Hydraulic cylinder stroke position feedback, CNC slide tables, injection molding machine stroke, valve positioners. Direct absolute position sensing; no complex decoding electronics required; low cost; simple DC voltage readout. Mechanical wiper friction causes physical wear over time; limited speed capability; vulnerable to dust and vibration noise.
Rotary Potentiometer RC servo motor position feedback, robot joint angle sensing, throttle position sensors (TPS), crane boom angle detection. Wide angular range options (single-turn vs multi-turn); absolute position memory upon power cycle; high reliability (conductive plastic tracks). Mechanical stop limits; loading error occurs when driving low-impedance loads; wiping noise at high RPM.

Numerical Problems: Sensor Interfacing & Motor Control

Problem 1: Linear Potentiometer Interfaced with PMDC Linear Actuator

Scenario: A PMDC motor drives a lead screw linear actuator with a stroke length $L_T = 250\text{ mm}$. A linear potentiometer of total resistance $R_T = 10\text{ k}\Omega$ is mounted parallel to the actuator stroke. The potentiometer is energized with a regulated excitation voltage $V_{in} = 10.0\text{ V DC}$. The output signal is connected to an ADC with an input resistance $R_L = 100\text{ k}\Omega$. When the motor moves the shaft to $x = 100\text{ mm}$, calculate:

  1. The ideal output voltage ($V_{ideal}$) ignoring loading effect.
  2. The actual loaded output voltage ($V_{loaded}$) and the resulting percentage loading error.

Step-by-Step Solution:

1. Ideal Voltage Calculation ($V_{ideal}$):

$$V_{\text{ideal}} = V_{\text{in}} \times \left( \frac{x}{L_T} \right) = 10.0 \times \left( \frac{100}{250} \right) = 4.000 \text{ V}$$

2. Equivalent Resistance Network: Resistance from GND to wiper is $R_1$, and top segment is $R_2$:

$$R_1 = R_T \times \left( \frac{x}{L_T} \right) = 10\text{ k}\Omega \times 0.40 = 4\text{ k}\Omega$$
$$R_2 = R_T - R_1 = 10\text{ k}\Omega - 4\text{ k}\Omega = 6\text{ k}\Omega$$

3. Parallel Combination with Load ($R_p$):

$$R_p = \frac{R_1 \times R_L}{R_1 + R_L} = \frac{4 \times 100}{4 + 100} = \frac{400}{104} = 3.846\text{ k}\Omega$$

4. Actual Loaded Output Voltage ($V_{loaded}$):

$$V_{\text{loaded}} = V_{\text{in}} \times \left( \frac{R_p}{R_2 + R_p} \right) = 10.0 \times \left( \frac{3.846}{6 + 3.846} \right) = 3.906\text{ V}$$

5. Percentage Loading Error:

$$\text{Loading Error (\%)} = \frac{V_{\text{loaded}} - V_{\text{ideal}}}{V_{\text{ideal}}} \times 100 = \frac{3.906 - 4.000}{4.000} \times 100 = -2.35\%$$

Problem 2: Rotary Potentiometer in DC Servo Motor Closed-Loop Position Control

Scenario: A 10-turn continuous precision rotary potentiometer ($3600^\circ$ total electrical angle, $R_T = 5\text{ k}\Omega$) acts as position feedback for an industrial DC Servo Motor arm. The excitation voltage is $V_{in} = 5.0\text{ V}$. The output drives a 12-bit Analog-to-Digital Converter (ADC) operating over a $0\text{ to }5\text{ V}$ input range.

  1. Calculate the potentiometer sensitivity $K_p$ in $\text{mV/degree}$.
  2. Determine the minimum detectable angular change ($\Delta\theta_{min}$) corresponding to $1\text{ LSB}$ of the 12-bit ADC.
  3. If the servo shaft rotates at $\omega = 45\text{ RPM}$, calculate the rate of change of output voltage ($dV_{out}/dt$).

Step-by-Step Solution:

1. Potentiometer Sensitivity ($K_p$):

$$K_p = \frac{V_{\text{in}}}{\theta_T} = \frac{5.0\text{ V}}{3600^\circ} = 0.0013888\text{ V/deg} = 1.389\text{ mV/deg}$$

2. ADC Voltage Resolution per LSB ($V_{LSB}$): For a 12-bit ADC ($2^{12} = 4096$ levels):

$$V_{LSB} = \frac{V_{\text{ref}}}{2^n} = \frac{5.0\text{ V}}{4096} = 0.0012207\text{ V} = 1.221\text{ mV}$$

3. Minimum Detectable Angular Change ($\Delta\theta_{min}$):

$$\Delta\theta_{min} = \frac{V_{LSB}}{K_p} = \frac{1.2207\text{ mV}}{1.3888\text{ mV/deg}} = 0.879^\circ$$

4. Rate of Output Voltage Change ($dV_{out}/dt$): Convert speed $\omega$ to degrees per second ($\text{deg/s}$):

$$\frac{d\theta}{dt} = 45\text{ RPM} \times \left( \frac{360^\circ}{60\text{ s}} \right) = 270\text{ deg/s}$$
$$\frac{dV_{out}}{dt} = K_p \times \frac{d\theta}{dt} = 0.0013888\text{ V/deg} \times 270\text{ deg/s} = 0.375\text{ V/s}$$

Problem 3: BLDC Motor Robotic Arm Joint Interfacing

Scenario: A BLDC motor drives a robotic joint through a $100:1$ harmonic gear reducer. A single-turn rotary potentiometer ($\theta_T = 300^\circ$, $V_{in} = 10\text{ V}$) is mounted directly on the output arm to measure actual joint angle $\theta_{arm}$. The BLDC motor rotates at $N_m = 1500\text{ RPM}$.

  1. Calculate the output arm speed in degrees per second ($\text{deg/s}$).
  2. Calculate the time required for the potentiometer output voltage to ramp from $1.5\text{ V}$ to $6.5\text{ V}$.

Step-by-Step Solution:

1. Arm Rotational Speed ($N_{arm}$):

$$N_{arm} = \frac{N_m}{GR} = \frac{1500}{100} = 15\text{ RPM}$$

2. Arm Angular Velocity ($\omega_{arm}$ in deg/s):

$$\omega_{arm} = 15\text{ RPM} \times \left( \frac{360^\circ}{60\text{ s}} \right) = 90\text{ deg/s}$$

3. Angular Displacement ($\Delta\theta$) for Given Voltage Change:

$$\Delta V = 6.5\text{ V} - 1.5\text{ V} = 5.0\text{ V}$$
$$\Delta\theta = \theta_T \times \left( \frac{\Delta V}{V_{\text{in}}} \right) = 300^\circ \times \left( \frac{5.0}{10.0} \right) = 150^\circ$$

4. Time Required ($t$):

$$t = \frac{\Delta\theta}{\omega_{arm}} = \frac{150^\circ}{90\text{ deg/s}} = 1.667\text{ seconds}$$

Problem 4: Stepper Motor Driven Table Calibration using Linear Potentiometer

Scenario: A microstepping stepper motor ($1.8^\circ/\text{step}$, operated at 8 microsteps/step) drives a precision slide table via a lead screw with pitch $P = 4\text{ mm/rev}$. A linear potentiometer ($L_T = 200\text{ mm}$, $V_{in} = 5\text{ V}$) provides position verification. If the controller outputs a pulse train of $f = 3.2\text{ kHz}$ to the drive, calculate the change in potentiometer output voltage per millisecond ($\Delta V/\Delta t$).

Step-by-Step Solution:

1. Total Microsteps per Revolution ($N_{micro}$):

$$N_{micro} = \left( \frac{360^\circ}{1.8^\circ} \right) \times 8 = 200 \times 8 = 1600\text{ microsteps/rev}$$

2. Linear Speed of Slide Table ($v$):

$$n_{rev} = \frac{f}{N_{micro}} = \frac{3200\text{ pulses/s}}{1600\text{ pulses/rev}} = 2\text{ rev/s}$$
$$v = n_{rev} \times P = 2\text{ rev/s} \times 4\text{ mm/rev} = 8\text{ mm/s}$$

3. Linear Sensitivity of Potentiometer ($K_L$):

$$K_L = \frac{V_{\text{in}}}{L_T} = \frac{5\text{ V}}{200\text{ mm}} = 0.025\text{ V/mm}$$

4. Voltage Change Rate per Millisecond ($\Delta V / \Delta t$):

$$\frac{\Delta V}{\Delta t} = K_L \times v = 0.025\text{ V/mm} \times 8\text{ mm/s} = 0.20\text{ V/s} = 0.20\text{ mV/ms}$$

Problem 5: AC Induction Motor Motorized Valve Position Feedback

Scenario: A 3-phase, 4-pole, $60\text{ Hz}$ AC Induction Motor drives a motorized flow control valve gear mechanism. The motor runs at a rated slip $s = 5\%$. The reduction gearbox has a ratio of $GR = 180:1$. The output gear turns a rotary potentiometer ($\theta_T = 270^\circ$, $V_{in} = 10\text{ V}$) over its full scale to open the valve completely from $0^\circ$ to $90^\circ$. Calculate the time taken to fully open the valve and the corresponding potentiometer output voltage change.

Step-by-Step Solution:

1. Synchronous Speed ($N_s$) & Rotor Speed ($N_r$):

$$N_s = \frac{120 \times f}{P} = \frac{120 \times 60}{4} = 1800\text{ RPM}$$
$$N_r = N_s \times (1 - s) = 1800 \times (1 - 0.05) = 1710\text{ RPM}$$

2. Gearbox Output Speed ($N_{valve}$):

$$N_{valve} = \frac{N_r}{GR} = \frac{1710}{180} = 9.5\text{ RPM}$$

3. Angular Speed of Valve ($\omega_{valve}$ in deg/s):

$$\omega_{valve} = 9.5\text{ RPM} \times \left( \frac{360^\circ}{60\text{ s}} \right) = 57\text{ deg/s}$$

4. Time to Open Valve from $0^\circ$ to $90^\circ$ ($t_{open}$):

$$t_{open} = \frac{90^\circ}{57\text{ deg/s}} = 1.579\text{ seconds}$$

5. Potentiometer Output Voltage Change ($\Delta V_{out}$):

$$\Delta V_{out} = V_{\text{in}} \times \left( \frac{\Delta\theta}{\theta_T} \right) = 10.0 \times \left( \frac{90^\circ}{270^\circ} \right) = 3.333\text{ V}$$
