Numerical Engineering Problems: Bandwidth & Data Ingestion Budgeting

Problem 1: MQTT Network Bandwidth Estimation for a Manufacturing Unit

Scenario: An automotive stamping unit installs $N = 400$ smart vibration sensors on its press line. Sensors package data into JSON payloads transmitted over an MQTT broker connection:

  • JSON Data Payload Size: $64\text{ bytes}$
  • MQTT Header & Topic Overhead: $16\text{ bytes}$
  • TCP/IP & Frame Overhead: $54\text{ bytes}$
  • Publish Rate ($f_{pub}$): $2\text{ Hz}$ per sensor (2 packets per second).

Calculate:

  1. The total packet size ($S_{frame}$) per telemetry message.
  2. The total continuous bandwidth requirement for the entire network in $\text{Kbps}$ and $\text{Mbps}$.
  3. The total raw data volume ingested by the broker over a 24-hour shift in gigabytes ($\text{GB}$).

Step-by-Step Solution:

1. Single Packet Frame Size ($S_{frame}$):

$$S_{frame} = S_{payload} + S_{MQTT} + S_{Network} = 64 + 16 + 54 = 134\text{ bytes/message}$$

2. Total Continuous Network Bandwidth:

$$\text{Message Rate} = 400\text{ nodes} \times 2\text{ msgs/sec} = 800\text{ msgs/sec}$$
$$\text{Data Rate} = 800\text{ msgs/sec} \times 134\text{ bytes/msg} = 107,200\text{ bytes/sec}$$
$$\text{Bandwidth (Kbps)} = \frac{107,200 \times 8}{1,000} = 857.6\text{ Kbps}$$
$$\text{Bandwidth (Mbps)} = \frac{857.6}{1,000} \approx 0.858\text{ Mbps}$$

3. Total 24-Hour Shift Data Volume:

$$\text{Data Volume} = \frac{107,200\text{ bytes/sec} \times (24 \times 3,600\text{ sec})}{1,024^3} \approx 8.627\text{ GB}$$

Problem 2: Time-Series Database Storage Capacity Sizing for a Power Plant

Scenario: A power generation utility manages $M = 12$ thermal power units. Each unit logs $N_{tags} = 1,500$ operational tags into a cloud Time-Series Database (TSDB):

  • Sampling Frequency: $1\text{ Hz}$ (1 sample per second per tag).
  • Uncompressed Sample Size: Timestamp (8 bytes) + Value (8 bytes) = $16\text{ bytes/sample}$.
  • The TSDB applies lossless Gorilla compression, reducing storage footprint by $4:1$ ($25\%$ retained size).

Calculate:

  1. The raw uncompressed data ingestion rate across all 12 units in megabytes per second ($\text{MB/s}$).
  2. The effective compressed data storage rate per second in kilobytes per second ($\text{KB/s}$).
  3. The total annual compressed storage required for $1\text{ year}$ ($365\text{ days}$) of continuous operational telemetry in terabytes ($\text{TB}$).

Step-by-Step Solution:

1. Raw Ingestion Rate:

$$\text{Total Active Tags} = 12\text{ units} \times 1,500\text{ tags} = 18,000\text{ tags}$$
$$\text{Raw Rate} = 18,000\text{ samples/sec} \times 16\text{ bytes} = 288,000\text{ bytes/sec} = 0.288\text{ MB/s}$$

2. Compressed Ingestion Rate:

$$\text{Compressed Rate} = \frac{288,000\text{ bytes/sec}}{4} = 72,000\text{ bytes/sec} = 72\text{ KB/s}$$

3. Annual Compressed Storage Capacity Budget:

$$\text{Annual Storage} = \frac{72,000\text{ bytes/sec} \times 31,536,000\text{ sec/year}}{1,024^4} \approx 2.065\text{ TiB (or } 2.271\text{ TB decimal)}$$
