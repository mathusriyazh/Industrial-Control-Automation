Chapter 27: Hardware Integration – Interfacing PLCs with Industrial Field Devices

This chapter covers the electrical and physical interfacing of PLCs with discrete and analog field hardware. Topics include PNP/NPN sinking and sourcing sensor wiring, 2-wire vs 4-wire $4\text{--}20\text{ mA}$ current loops, relay interlocks, inductive surge suppression, and loop burden calculations.

1. Discrete Wiring Topologies: Sinking (NPN) vs Sourcing (PNP)

Hardware Hardware Image Reference


Conventional Current Flow Rules

Understanding conventional current flow direction is essential when connecting discrete sensors (solid-state 3-wire proximity switches) to PLC input modules:

  • Sourcing (PNP Transistor): The sensor acts as a current source, supplying positive $24\text{V DC}$ current out to the PLC input terminal. Requires a Sinking Input Module.
  • Sinking (NPN Transistor): The sensor acts as a current sink, drawing current from the PLC input terminal down to DC Ground ($0\text{V}$). Requires a Sourcing Input Module.

Rule of thumb: Sourcing provides $V_+$, Sinking provides Ground ($0\text{V}$).

2. Analog Interfacing & Industrial Field Actuators

$4\text{--}20\text{ mA}$ Industrial Current Loops

Analog field transmitters convert physical parameters (temperature, pressure, flow) into proportional electric signals. The $4\text{--}20\text{ mA}$ standard is favored over $0\text{--}10\text{ V}$ due to zero voltage drop over long wire distances and built-in fault detection:

  • Live Zero ($4\text{ mA}$): $4\text{ mA}$ represents $0\%$ scale. A reading of $0\text{ mA}$ explicitly flags a broken wire or power loss.
  • Full Scale ($20\text{ mA}$): $20\text{ mA}$ represents $100\%$ measurement span.
  • Surge Protection: Inductive output loads like solenoid valves and relays must use freewheeling flyback diodes across DC coils or RC snubbers across AC coils to suppress back-EMF spikes:
$$V_{spike} = -L \frac{di}{dt}$$

Numerical Problems: Loop Burden & Sensing Resistor Scaling

Problem 1: 2-Wire Loop Maximum Allowable Wire Resistance

Scenario: A $24\text{V DC}$ loop-powered temperature transmitter requires a minimum operating voltage $V_{tx\_min} = 11.5\text{ V DC}$ to power its internal electronics. The PLC analog input card uses an internal $R_{sense} = 250\ \Omega$ current-sensing resistor. The signal line operates up to a maximum full-scale current $I_{max} = 20\text{ mA}$.

Calculate:

  1. The voltage drop across the PLC input sense resistor $V_{sense}$ at $20\text{ mA}$.
  2. The maximum allowable voltage drop $V_{wire\_max}$ available for field wiring.
  3. The maximum allowable loop wire resistance $R_{wire\_max}$ in Ohms ($\Omega$).
  4. The maximum physical cable length if using 22 AWG copper wire ($R_{AWG} = 53\ \Omega/\text{km}$ loop pair).

Step-by-Step Solution:

1. Compute Sense Resistor Voltage Drop ($V_{sense}$):

$$V_{sense} = I_{max} \times R_{sense} = 0.020\text{ A} \times 250\ \Omega = 5.0\text{ V}$$

2. Compute Maximum Allowable Wiring Voltage Drop ($V_{wire\_max}$):

$$V_{wire\_max} = V_{supply} - V_{tx\_min} - V_{sense} = 24.0\text{ V} - 11.5\text{ V} - 5.0\text{ V} = 7.5\text{ V}$$

3. Compute Maximum Loop Resistance ($R_{wire\_max}$):

$$R_{wire\_max} = \frac{V_{wire\_max}}{I_{max}} = \frac{7.5\text{ V}}{0.020\text{ A}} = 375\ \Omega$$

4. Compute Maximum Cable Run Distance:

$$\text{Max Cable Distance} = \frac{R_{wire\_max}}{R_{AWG}} = \frac{375\ \Omega}{53\ \Omega/\text{km}} \approx 7.075\text{ km} = 7,075\text{ meters}$$

Problem 2: Solenoid Surge Suppression Diode Rating

Scenario: A PLC output transistor module controls a $24\text{V DC}$ hydraulic solenoid valve drawing a nominal current $I_{coil} = 1.8\text{ A}$ with coil inductance $L = 0.45\text{ H}$. Upon turn-off, a freewheeling flyback diode dissipates the inductive energy.

Calculate:

  1. The inductive energy $E_{stored}$ stored in the solenoid magnetic field in Joules ($\text{J}$).
  2. The minimum required Peak Inverse Voltage (PIV) rating for the flyback diode using a standard safety factor of $2.5\times$.

Step-by-Step Solution:

1. Calculate Magnetic Stored Energy ($E_{stored}$):

$$E_{stored} = \frac{1}{2} L I_{coil}^2 = \frac{1}{2} (0.45\text{ H}) (1.8\text{ A})^2 = 0.225 \times 3.24 = 0.729\text{ Joules}$$

2. Compute Diode Peak Inverse Voltage (PIV) Rating:

$$\text{PIV}_{min} = V_{supply} \times \text{Safety Factor} = 24\text{ V} \times 2.5 = 60.0\text{ V DC}$$
