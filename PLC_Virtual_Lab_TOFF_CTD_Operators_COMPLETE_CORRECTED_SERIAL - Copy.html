Parallel Branch Operation

Create a branch and drag its START and END handles to position the branch on the main ladder line.

Series = AND     Parallel = OR

Example: Y0 = ((X0 AND X3) OR (X1 AND X2)) AND X4

When one parallel path is TRUE, the branch is TRUE.

How to use branch

Step 1
Click Parallel Branch.

Step 2
Drag the orange START handle to the required point on the main line.

Step 3
Drag the orange END handle to the required point on the main line.

Step 4
Drag contacts into the upper or lower branch.

Step 5
Toggle X0, X1 etc.

Step 6
Press RUN.
