What Each Component Does

Component Function
PLC Executes the control logic and decides when the motor should run.
Relay Provides an electrical interface between the PLC output and the contactor circuit.
Contactor Switches the high-power motor supply.
Motor Converts electrical energy into mechanical rotation.
HMI Allows an operator to start, stop and monitor the machine.
SCADA Provides supervisory monitoring, alarms, trends and system-level visualization.
