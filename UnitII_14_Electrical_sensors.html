Chapter 14: Electrical Sensing – Isolated Voltage & Current Transducers

This chapter covers galvanic isolation methods for measuring high power electrical variables in electric motor drives and automated power control systems. Topics include optical & magnetic barrier isolation in Isolated Voltage Sensor Modules, non-contact flux measurement in Hall Effect Current Sensors (Open-Loop & Closed-Loop), and motor current/bus-voltage calculations.

1. Isolated Voltage Sensor Module

Industrial Hardware Image


Working Principle

High-voltage DC bus lines (e.g., $400\text{V} - 800\text{V}$ in motor drives) cannot be directly fed to low-voltage microcontrollers ($3.3\text{V}/5\text{V}$). Isolated Voltage Sensor Modules step down high voltage using a precision resistive divider network and transmit the scaled signal across a high-voltage galvanic isolation barrier (opto-isolation or capacitive isolation amplifier).

For a high input voltage $V_{IN}$, precision input resistors $R_1$ and $R_2$ step down the voltage to a safe level $V_{sense}$:

$$V_{sense} = V_{IN} \times \frac{R_2}{R_1 + R_2}$$

The isolation amplifier modulates this small analog signal, transfers it across the isolation barrier via optical or capacitive coupling, and outputs an isolated proportional voltage $V_{OUT}$:

$$V_{OUT} = G_{iso} \times V_{sense} = G_{iso} \times V_{IN} \times \left( \frac{R_2}{R_1 + R_2} \right)$$

Where $G_{iso}$ is the gain of the isolation amplifier stage. This prevents ground loops and protects control electronics from high voltage surges.

2. Hall Effect Current Sensor (ACS712 / Open & Closed Loop)

Industrial Hardware Image


Working Principle

A Hall Effect Current Sensor measures primary AC or DC motor current without physical electrical connection (galvanically isolated). As current $I_p$ flows through an internal low-resistance copper conductor track, it generates a proportional magnetic field $B$ according to Ampere’s Law:

$$B = \frac{\mu_0 \cdot I_p}{2\pi \cdot r}$$

An integrated Hall IC converts this magnetic flux into a proportional transverse Hall voltage $V_H$. The sensor module conditions this signal into a linear output voltage $V_{OUT}$ proportional to primary current:

$$V_{OUT} = V_{zero} + (S_{sens} \times I_p)$$

Where $V_{zero}$ is the zero-current offset voltage (typically $2.5\text{V}$ for a $5\text{V}$ supply) and $S_{sens}$ is the sensor sensitivity constant (expressed in $\text{mV/A}$).

Numerical Problems: Voltage & Current Sensing in Electric Motor Drives

Problem 1: DC Bus Voltage Monitoring in an Industrial Motor Drive

Scenario: An isolated voltage sensor module measures the DC bus voltage of an industrial variable frequency drive (VFD). The module has a voltage divider with $R_1 = 495\text{ k}\Omega$ and $R_2 = 5\text{ k}\Omega$. The internal isolation amplifier has a unity gain ($G_{iso} = 1.0$). The output is connected to a 12-bit microcontroller ADC with a reference voltage $V_{ref} = 3.3\text{V}$. Calculate:

  1. The voltage step-down attenuation ratio of the resistor network.
  2. The module output voltage $V_{OUT}$ when the DC bus voltage is $V_{DC} = 300\text{V}$.
  3. The ADC digital output count for $V_{DC} = 300\text{V}$.
  4. The maximum allowable DC bus voltage before the ADC saturates ($3.3\text{V}$).

Step-by-Step Solution:

1. Attenuation Ratio ($K_{div}$):

$$K_{div} = \frac{R_2}{R_1 + R_2} = \frac{5\text{ k}\Omega}{495\text{ k}\Omega + 5\text{ k}\Omega} = \frac{5}{500} = 0.01\ (100:1\text{ attenuation})$$

2. Sensor Output Voltage ($V_{OUT}$) at $300\text{V}$:

$$V_{OUT} = V_{DC} \times K_{div} \times G_{iso} = 300\text{V} \times 0.01 \times 1.0 = 3.00\text{ V}$$

3. 12-Bit ADC Digital Count: A 12-bit ADC has $2^{12} = 4096$ levels ($0\text{ to }4095$):

$$\text{ADC Count} = \left( \frac{V_{OUT}}{V_{ref}} \right) \times 4095 = \left( \frac{3.00\text{V}}{3.30\text{V}} \right) \times 4095 = 3722.7 \approx 3723\text{ counts}$$

4. Maximum Measurable DC Voltage ($V_{DC,max}$): At $V_{OUT} = 3.3\text{V}$:

$$V_{DC,max} = \frac{V_{ref}}{K_{div}} = \frac{3.30\text{V}}{0.01} = 330\text{ Volts}$$

Problem 2: Hall Effect Sensor Current Measurement in a DC Motor

Scenario: A bi-directional Hall effect current sensor (ACS712-20A model) is powered by a $5.0\text{V}$ DC supply. It has a zero-current output voltage $V_{zero} = 2.50\text{V}$ and a rated sensitivity $S_{sens} = 100\text{ mV/A}$ ($0.100\text{ V/A}$). Calculate:

  1. The sensor output voltage when the motor draws a forward current $I_p = +12\text{ A}$.
  2. The sensor output voltage when regenerative braking causes a reverse current $I_p = -8\text{ A}$.
  3. The measured motor current if a microcontroller reads a sensor output voltage $V_{OUT} = 3.85\text{ V}$.

Step-by-Step Solution:

1. Output Voltage for Forward Current ($+12\text{A}$):

$$V_{OUT} = V_{zero} + (S_{sens} \times I_p) = 2.50\text{V} + (0.100\text{ V/A} \times 12\text{ A}) = 2.50 + 1.20 = 3.70\text{ Volts}$$

2. Output Voltage for Reverse Current ($-8\text{A}$):

$$V_{OUT} = V_{zero} + (S_{sens} \times I_p) = 2.50\text{V} + (0.100\text{ V/A} \times (-8\text{ A})) = 2.50 - 0.80 = 1.70\text{ Volts}$$

3. Calculate Current from Measured Output ($3.85\text{V}$): Rearranging the sensor transfer formula:

$$I_p = \frac{V_{OUT} - V_{zero}}{S_{sens}} = \frac{3.85\text{V} - 2.50\text{V}}{0.100\text{ V/A}} = \frac{1.35\text{V}}{0.100\text{ V/A}} = +13.5\text{ Amperes}$$

Problem 3: Power Dissipation & Efficiency Comparison

Scenario: A motor drive phase current of $I_{rms} = 50\text{ A}$ is measured using two different methods:

  • Option A: A precision current shunt resistor $R_{shunt} = 2\text{ m}\Omega$.
  • Option B: A Hall effect current sensor with an internal primary conductor resistance $R_{hall} = 0.2\text{ m}\Omega$.

Calculate the power dissipated ($P_{loss}$) in watts for both sensors and determine the power saved by using the Hall effect transducer.

Step-by-Step Solution:

1. Power Loss in Shunt Resistor (Option A):

$$P_{shunt} = I_{rms}^2 \times R_{shunt} = (50\text{ A})^2 \times (2.0 \times 10^{-3}\ \Omega) = 2500 \times 0.002 = 5.00\text{ Watts}$$

2. Power Loss in Hall Sensor Conductor (Option B):

$$P_{hall} = I_{rms}^2 \times R_{hall} = (50\text{ A})^2 \times (0.2 \times 10^{-3}\ \Omega) = 2500 \times 0.0002 = 0.50\text{ Watts}$$

3. Power Saved:

$$\Delta P = P_{shunt} - P_{hall} = 5.00\text{W} - 0.50\text{W} = 4.50\text{ Watts (90\% reduction in thermal loss)}$$
