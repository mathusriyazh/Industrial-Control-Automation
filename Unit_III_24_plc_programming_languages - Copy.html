Chapter 25: Industrial Programming Languages (IEC 61131-3)

This chapter covers the standard industrial automation control paradigms under IEC 61131-3: Ladder Logic (LD), Function Block Diagram (FBD), and Structured Text (ST). It includes comparative logic implementations, scan execution flow, and mathematical signal processing code.

1. Ladder Logic (LD) – Relay Rung Execution

Working Principle & Logic Continuity

Ladder Logic (LD) is a graphical programming language derived from hardwired electromechanical relay circuits. Programs consist of vertical power rails and horizontal "rungs" containing contacts (inputs) and coils (outputs).

Power flows symbolically from the left high-voltage rail ($V_+$) to the right return rail ($0\text{V}$) when logical continuity is satisfied. Standard boolean contact symbols include:

  • Normally Open Contact (NO) -| |-: Evaluates TRUE ($1$) when its assigned bit address is ON.
  • Normally Closed Contact (NC) -|/|-: Evaluates TRUE ($1$) when its assigned bit address is OFF.
  • Output Coil -( )-: Energized TRUE ($1$) when power flow reaches the coil.

Logical AND operations are formed by placing contacts in series, while OR operations are formed by placing contacts in parallel branches.

2. Function Block Diagram (FBD) & Structured Text (ST)

Function Block Diagram (FBD)

FBD is a graphical language where signal flows from left inputs to right outputs through re-usable algorithm blocks. It is ideal for continuous control systems, analog signal scaling, and PID loop regulation.

FBD Signal Processing: Error Calculation into PID Loop

Structured Text (ST) Code Block

Structured Text (ST) is a high-level, block-structured language resembling Pascal or C. It excels at complex mathematical operations, array indexing, data manipulation, and high-speed algorithm processing.

// ========================================== // IEC 61131-3 Structured Text (ST) Module // Analog Pressure Scaling & Alarm Detection // ========================================== PROGRAM Pressure_Control VAR_INPUT Raw_Input : INT; // Raw 14-bit ADC (0..16383) High_Limit : REAL := 80.0; // High Pressure Alarm Threshold END_VAR VAR_OUTPUT Scaled_PSI : REAL; // Scaled Engineering Units Alarm_Active : BOOL; // Alarm Output Relay Bit END_VAR // Linear Scale Transformation Equation: Scaled_PSI := (INT_TO_REAL(Raw_Input) / 16383.0) * 100.0; // Alarm Evaluation Logic IF Scaled_PSI >= High_Limit THEN Alarm_Active := TRUE; ELSE Alarm_Active := FALSE; END_IF; END_PROGRAM

Comparative Analysis: IEC 61131-3 Programming Paradigms

Language Name Syntax Type Primary Strengths Optimal Industrial Applications
Ladder Logic (LD) Graphical (Relay Rungs). Easy troubleshooting for field technicians; clear boolean state display. Discrete machine interlocks, conveyor systems, motor control panels.
Function Block Diagram (FBD) Graphical (Signal Flow Blocks). Highly visual data tracking; simple integration of pre-built algorithms. Process control, PID loop networks, motion control profiles.
Structured Text (ST) Textual (Block Structured High-Level). Handles complex math, loops (FOR/WHILE), string handling, and array structures efficiently. Data logging, recipe management, kinematic transformations, complex batch operations.
Sequential Function Chart (SFC) Graphical Flowchart (Steps/Transitions). Organizes complex state machines and multi-step sequential tasks clearly. Batch processing plants, assembly line sequencing, automated startup/shutdown routines.

Numerical Problems: Signal Scaling & Timer Register Computation

Problem 1: Analog Sensor Signal Normalization in ST

Scenario: A PLC Structured Text function receives an analog input integer $N_{raw}$ from a 12-bit ADC module ($0\text{ to } 4095\text{ counts}$) representing a flow rate sensor calibrated from $0.0\text{ to } 250.0\text{ Liters/min}$.

Determine:

  1. The explicit mathematical transfer function used in Structured Text to output scaled float value $Q_{scaled}$.
  2. The calculated flow rate $Q_{scaled}$ when the ADC raw input register reads $2867\text{ counts}$.

Step-by-Step Solution:

1. Formulate Transfer Function:

$$Q_{scaled} = \left( \frac{N_{raw} - N_{min}}{N_{max} - N_{min}} \right) \times (Q_{max} - Q_{min}) + Q_{min}$$
$$Q_{scaled} = \left( \frac{N_{raw}}{4095.0} \right) \times 250.0$$

2. Compute Flow Rate for $N_{raw} = 2867$:

$$Q_{scaled} = \left( \frac{2867}{4095.0} \right) \times 250.0 = 0.70012 \times 250.0 = 175.03\text{ L/min}$$

Problem 2: On-Delay Timer (TON) Preset Memory Calculation

Scenario: An IEC 61131-3 On-Delay Timer (TON) function block uses a $10\text{ ms}$ internal tick timer base ($0.01\text{ seconds}$). The process requires an output delay time $T_{delay} = 45.5\text{ seconds}$ before energizing a lube pump.

Calculate:

  1. The integer value stored in the timer preset register (TON.PT).
  2. The elapsed time value in seconds when the timer count register reaches $2300\text{ ticks}$.

Step-by-Step Solution:

1. Compute Preset Register Count Value:

$$\text{Preset Count (PT)} = \frac{T_{delay}}{\text{Time Base}} = \frac{45.5\text{ s}}{0.01\text{ s/tick}} = 4550\text{ ticks}$$

2. Compute Elapsed Time for $2300\text{ ticks}$:

$$T_{elapsed} = \text{Ticks} \times \text{Time Base} = 2300 \times 0.01\text{ s} = 23.0\text{ seconds}$$
