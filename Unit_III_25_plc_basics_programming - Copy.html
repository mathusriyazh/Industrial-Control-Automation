1. Fundamental Digital Logic Gates in Ladder Diagrams

Combinational Boolean Logic

Digital logic circuits are constructed in PLC Ladder Logic using combinations of Normally Open (NO) and Normally Closed (NC) contacts:

  • AND Gate: Inputs connected in series. Output $Y = A \cdot B$.
  • OR Gate: Inputs connected in parallel. Output $Y = A + B$.
  • NAND Gate: Parallel Normally Closed contacts. Output $Y = \overline{A \cdot B} = \bar{A} + \bar{B}$.
  • NOR Gate: Series Normally Closed contacts. Output $Y = \overline{A + B} = \bar{A} \cdot \bar{B}$.
  • XOR Gate: Combination of NO and NC contacts in parallel branches. Output $Y = A\bar{B} + \bar{A}B$.

2. Industrial Timers, Counters & Sequencer Functions

Timer & Counter Architecture

PLC control software includes built-in timing and counting instructions:

  • On-Delay Timer (TON): Begins incrementing its Accumulated value ($ACC$) when the rung becomes TRUE. The Done bit ($DN$) sets TRUE when $ACC \ge Preset\ (PRE)$.
  • Off-Delay Timer (TOF): Rung goes FALSE $\rightarrow$ Timer begins counting down the off-delay duration.
  • Up Counter (CTU): Increments $ACC$ by 1 on every OFF-to-ON false-to-true rung transition.
  • Sequencer Output (SQO): Steps through an array of memory words (masks) to output multi-step bit patterns to field actuators sequentially.

Numerical Problems: Timer Parameter Calculations & Counter Batching

Problem 1: Cascaded TON Timer Delay Calculation

Scenario: A conveyor system uses three cascaded On-Delay Timers ($T_1, T_2, T_3$) to sequentially start three conveyor drives. The parameters are:

  • $T_1$: Time Base $= 0.1\text{ s}$, $PRE_1 = 150$
  • $T_2$: Time Base $= 0.01\text{ s}$, $PRE_2 = 2500$
  • $T_3$: Time Base $= 1.0\text{ s}$, $PRE_3 = 12$

Calculate:

  1. The time delay of each individual timer ($t_1, t_2, t_3$) in seconds.
  2. The total sequence time delay $T_{total}$ from initial start command to motor 3 energization.

Step-by-Step Solution:

1. Compute Individual Delays:

$$t_1 = PRE_1 \times \text{Time Base}_1 = 150 \times 0.1\text{ s} = 15.0\text{ seconds}$$
$$t_2 = PRE_2 \times \text{Time Base}_2 = 2500 \times 0.01\text{ s} = 25.0\text{ seconds}$$
$$t_3 = PRE_3 \times \text{Time Base}_3 = 12 \times 1.0\text{ s} = 12.0\text{ seconds}$$

2. Compute Total Cumulative Delay ($T_{total}$):

$$T_{total} = t_1 + t_2 + t_3 = 15.0\text{ s} + 25.0\text{ s} + 12.0\text{ s} = 52.0\text{ seconds}$$

Problem 2: Conveyor Batch Packing Counter Calculations

Scenario: A high-speed bottling line uses a proximity sensor attached to a CTU Up-Counter instruction ($C5:0$) to pack bottles into cases of 24. A second CTU counter ($C5:1$) tracks total packed cases per shift. The conveyor belt speed is $1.2\text{ m/s}$ with a bottle spacing of $0.15\text{ m}$.

Calculate:

  1. The pulse frequency $f_{sensor}$ from the proximity sensor in Hertz ($\text{Hz}$).
  2. The time required $t_{case}$ to fill one case of 24 bottles.
  3. The total count value in $C5:1$ after an 8-hour shift.

Step-by-Step Solution:

1. Calculate Proximity Sensor Pulse Frequency ($f_{sensor}$):

$$f_{sensor} = \frac{\text{Conveyor Speed}}{\text{Bottle Spacing}} = \frac{1.2\text{ m/s}}{0.15\text{ m}} = 8.0\text{ Hz}\quad (8\text{ bottles/second})$$

2. Calculate Time Per Case ($t_{case}$):

$$t_{case} = \frac{\text{Bottles per Case}}{f_{sensor}} = \frac{24\text{ bottles}}{8.0\text{ bottles/s}} = 3.0\text{ seconds}$$

3. Calculate Total Cases Packed in 8 Hours:

$$\text{Total Seconds} = 8\text{ hrs} \times 3600\text{ s/hr} = 28,800\text{ seconds}$$
$$\text{Cases Count (C5:1)} = \frac{28,800\text{ s}}{3.0\text{ s/case}} = 9,600\text{ cases}$$
