Core Real-Time Components

Real-time data acquisition and control systems bridge physical process dynamics with digital decision engines:

  • Signal Conditioning & ADC: Filters noise, amplifies weak sensor signals, and digitizes analog variables at fixed sampling intervals ($T_s$).
  • Deterministic RTOS Task Execution: Guarantees hard real-time execution of control algorithms (e.g., PID) without dynamic jitter or missed deadlines.
  • Actuator Output Generation: Converts calculated control outputs back to physical signals (DAC or PWM) to drive final control elements.

Numerical Problems: Sampling Rates & Loop Latency Budgeting

Problem 1: DAQ Nyquist Sampling Criteria and Bandwidth Throughput

Scenario: A real-time DAQ system monitors a high-speed vibration sensor mounted on a CNC spindle shaft. The highest relevant vibration harmonic occurs at $f_{max} = 12.5\text{ kHz}$. To prevent aliasing and enable accurate signal reconstruction, the system samples at $f_s = 4 \times f_{max}$. The DAQ board features a 16-bit ADC operating across 8 simultaneous differential channels.

Calculate:

  1. The minimum required sampling frequency $f_s$ and period $T_s$.
  2. The raw data output throughput generated by the 8-channel board in megabits per second ($\text{Mbps}$) and megabytes per second ($\text{MB/s}$).
  3. The total buffer memory required to store $10\text{ seconds}$ of uninterrupted vibration telemetry.

Step-by-Step Solution:

1. Compute Sampling Rate and Period:

$$f_s = 4 \times 12.5\text{ kHz} = 50\text{ kHz} = 50,000\text{ samples/sec per channel}$$
$$T_s = \frac{1}{f_s} = \frac{1}{50,000\text{ Hz}} = 20\ \mu\text{s}$$

2. Compute System Data Throughput:

$$\text{Total Sample Rate} = 8\text{ channels} \times 50,000\text{ samples/sec} = 400,000\text{ samples/sec}$$
$$\text{Bit Rate} = 400,000\text{ samples/sec} \times 16\text{ bits/sample} = 6,400,000\text{ bits/sec} = 6.4\text{ Mbps}$$
$$\text{Byte Rate} = \frac{6.4\text{ Mbps}}{8} = 0.8\text{ MB/s} = 800\text{ KB/s}$$

3. Compute Buffer Storage Requirement for 10 Seconds:

$$\text{Storage} = 0.8\text{ MB/s} \times 10\text{ seconds} = 8.0\text{ MB}$$

Problem 2: Real-Time Closed-Loop Latency Budget

Scenario: A hard real-time motion controller executes a digital PID algorithm. The dynamic process requires a control loop update rate of $f_{loop} = 2\text{ kHz}$ ($T_{loop} = 500\ \mu\text{s}$). The timing components within each loop iteration are:

  • Analog-to-Digital Conversion Time: $t_{adc} = 35\ \mu\text{s}$
  • Sensor Signal Filtering & Conditioning: $t_{filt} = 45\ \mu\text{s}$
  • Digital-to-Analog Output Update: $t_{dac} = 20\ \mu\text{s}$
  • Bus Communication Delay (Fieldbus): $t_{comm} = 110\ \mu\text{s}$

Calculate:

  1. The maximum time available ($t_{proc\_max}$) for the processor to execute the PID control code without missing its execution deadline.
  2. The maximum CPU load percentage consumed strictly by input/output and communication overhead ($t_{overhead} = t_{adc} + t_{filt} + t_{dac} + t_{comm}$).

Step-by-Step Solution:

1. Compute Maximum Allowed Computation Time ($t_{proc\_max}$):

$$T_{loop} = 500\ \mu\text{s}$$
$$t_{overhead} = t_{adc} + t_{filt} + t_{dac} + t_{comm} = 35\ \mu\text{s} + 45\ \mu\text{s} + 20\ \mu\text{s} + 110\ \mu\text{s} = 210\ \mu\text{s}$$
$$t_{proc\_max} = T_{loop} - t_{overhead} = 500\ \mu\text{s} - 210\ \mu\text{s} = 290\ \mu\text{s}$$

2. Compute Percentage of Loop Time Spent on I/O Overhead:

$$\text{Overhead Percentage} = \left( \frac{t_{overhead}}{T_{loop}} \right) \times 100\% = \left( \frac{210\ \mu\text{s}}{500\ \mu\text{s}} \right) \times 100\% = 42.0\%$$
