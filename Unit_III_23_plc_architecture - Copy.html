Chapter 24: Industrial Controllers – Architecture of Programmable Logic Controllers (PLC)

This chapter examines the internal hardware system architecture of Programmable Logic Controllers (PLCs), optical isolation safety interfaces, memory allocation structures, scan timing calculations, and cyclic execution dynamics.

1. Hardware Architecture & Continuous Scan Cycle

Hardware Hardware Image Reference


Core Architecture Overview

A Programmable Logic Controller (PLC) is an industrial microprocessor-based controller designed for real-time control of manufacturing processes. Its hardware architecture consists of five core elements:

  • Central Processing Unit (CPU): Executes the user program stored in non-volatile memory and manages systemic diagnostics.
  • Power Supply Module: Converts line AC voltage (120/240V AC) to regulated low-voltage DC (24V DC, 5V DC) for internal backplane buses and CPU microelectronics.
  • Input Module: Receives discrete or analog signals from field devices (switches, sensors) using optocouplers for high-voltage isolation.
  • Output Module: Drives field actuators (solenoids, relays, contactors) via solid-state switches or electromechanical contacts.
  • Memory Unit: Divided into RAM (data table/registers) and ROM/EEPROM (program storage).

The total operating time of a PLC during one complete processing sweep is governed by the total scan time $T_{scan}$:

$$T_{scan} = T_{input\_read} + T_{program\_exec} + T_{output\_write} + T_{overhead}$$

2. Optoisolation & Input Signal Conditioning

Optocoupler Electrical Isolation

To prevent field electrical transients, high-voltage surges, and ground loops from damaging sensitive 5V microprocessors, industrial PLC input cards employ Optoisolators (Optocouplers).

The optical isolation barrier converts incoming field current $I_{in}$ into light pulses using an Infrared LED, which photo-triggers a phototransistor on the microprocessor side:

$$I_{LED} = \frac{V_{in} - V_{LED}}{R_{limit}}$$

Where $V_{in}$ is the incoming field voltage (e.g., 24V DC), $V_{LED}$ is the forward voltage drop of the internal LED ($\approx 1.2\text{ to } 1.7\text{ V}$), and $R_{limit}$ is the current-limiting input resistor.

Numerical Problems: Scan Time, Memory Capacity & Analog Resolution

Problem 1: PLC Program Execution & Total Scan Time Calculation

Scenario: A modular industrial PLC controls an automated sorting line. Its instruction execution speed is $0.05\ \mu\text{s per basic instruction}$ and $0.40\ \mu\text{s per complex math block}$. The ladder logic program consists of $12,000\text{ basic instructions}$ and $800\text{ complex math blocks}$.

The module system specifications provide the following overhead times:

  • Input Module Discrete Read Sweep Time: $T_{input} = 0.85\text{ ms}$
  • Output Module Write Sweep Time: $T_{output} = 0.65\text{ ms}$
  • CPU Diagnostics & Network Communication Overhead: $T_{overhead} = 1.20\text{ ms}$

Determine:

  1. The program execution time $T_{program\_exec}$ in milliseconds.
  2. The total system scan time $T_{scan}$ in milliseconds.
  3. The maximum theoretical update frequency $f_{scan}$ in Hertz ($\text{Hz}$).

Step-by-Step Solution:

1. Calculate Program Execution Time ($T_{program\_exec}$):

$$T_{basic} = 12000 \times 0.05\ \mu\text{s} = 600\ \mu\text{s} = 0.60\text{ ms}$$
$$T_{math} = 800 \times 0.40\ \mu\text{s} = 320\ \mu\text{s} = 0.32\text{ ms}$$
$$T_{program\_exec} = T_{basic} + T_{math} = 0.60\text{ ms} + 0.32\text{ ms} = 0.92\text{ ms}$$

2. Calculate Total Scan Time ($T_{scan}$):

$$T_{scan} = T_{input} + T_{program\_exec} + T_{output} + T_{overhead}$$
$$T_{scan} = 0.85\text{ ms} + 0.92\text{ ms} + 0.65\text{ ms} + 1.20\text{ ms} = 3.62\text{ ms}$$

3. Calculate Update Frequency ($f_{scan}$):

$$f_{scan} = \frac{1}{T_{scan}} = \frac{1}{3.62 \times 10^{-3}\text{ s}} \approx 276.24\text{ Hz}$$

Problem 2: Analog Input Module Quantization & Voltage Resolution

Scenario: An analog input card accepts a $0\text{ to } 10\text{ V DC}$ pressure sensor signal and converts it using a 14-bit Analog-to-Digital Converter (ADC). The field pressure sensor ranges from $0\text{ to } 200\text{ PSI}$.

Calculate:

  1. The total number of discrete quantization levels ($2^N$) for the 14-bit ADC module.
  2. The voltage resolution per bit $\Delta V$ in millivolts ($\text{mV}$).
  3. The engineering unit pressure resolution $\Delta P$ in $\text{PSI per bit}$.
  4. The register integer value returned by the PLC when the input voltage is $6.40\text{ V DC}$.

Step-by-Step Solution:

1. Calculate Quantization Levels:

$$\text{Levels} = 2^{14} = 16,384\text{ counts (0 to 16,383)}$$

2. Calculate Voltage Resolution ($\Delta V$):

$$\Delta V = \frac{V_{max} - V_{min}}{2^N - 1} = \frac{10\text{ V} - 0\text{ V}}{16383} = 0.00061038\text{ V/count} = 0.6104\text{ mV/count}$$

3. Calculate Pressure Resolution ($\Delta P$):

$$\Delta P = \frac{200\text{ PSI}}{16383\text{ counts}} = 0.012207\text{ PSI/count}$$

4. Calculate Register Integer Value for $V_{in} = 6.40\text{ V}$:

$$\text{Register Value} = \text{Round}\left( \frac{V_{in}}{\Delta V} \right) = \text{Round}\left( \frac{6.40\text{ V}}{0.00061038\text{ V}} \right) = 10,485\text{ counts}$$
