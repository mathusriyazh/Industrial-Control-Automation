Chapter 9: Proximity Sensors & Motor Interfacing

This chapter covers the operating mechanics, electrical block architecture, hardware visual representations, practical industrial applications, and numerical calculations for Inductive, Capacitive, and Photoelectric proximity sensors interfaced with various electric motor drives.

1. Inductive Proximity Sensor

Industrial Hardware Image

Source / Royalty-Free License: Getty Images (Stock Photo 664564128)

Working Principle

Inductive proximity sensors detect ferrous and non-ferrous metallic targets using electromagnetic field induction. The internal oscillator creates a high-frequency alternating magnetic field at the sensing face. When a metallic object enters this field, eddy currents are induced inside the metal, causing energy loss and reducing oscillator amplitude. The trigger circuit detects this dampening and toggles the output stage.

2. Capacitive Proximity Sensor

Industrial Hardware Image


Working Principle

Capacitive proximity sensors detect both metallic and non-metallic targets (liquids, plastics, wood, grain). The sensing face incorporates two concentric metallic electrodes forming an open capacitor ($C$). As a target approaches, its dielectric constant ($\epsilon_r$) alters the capacitance between the plates. This shifts the internal RC oscillator circuit into oscillation, which is converted into an output signal.

3. Photoelectric Proximity Sensor

Industrial Hardware Image

Source / Royalty-Free License: Getty Images (Stock Photo 153162056)

Working Principle

Photoelectric sensors use an optical beam (Infrared or Laser) generated by an LED transmitter and received by a phototransistor. Operating modes include:

  • Through-Beam: Emitter and receiver face each other. Target breaks beam.
  • Retro-Reflective: Emitter/receiver in one housing; beam reflects off reflector target.
  • Diffuse-Reflective: Light reflects directly off the object surface.

Practical Applications, Advantages & Disadvantages

Sensor Type Target Compatibility Practical Applications Key Advantages Disadvantages
Inductive Ferrous / Non-ferrous Metals only CNC machine home positioning, gear speed counting, metal can line detection. Immune to dirt, water, and oil. High switching rate, highly durable. Zero detection range for non-metals. Short sensing distance (1–20mm).
Capacitive Metals, Plastics, Liquids, Glass, Wood Tank liquid level detection through non-metallic walls, box fill verification. Detects target material through non-metallic package walls. Adjustable gain. Sensitive to humidity, moisture buildup, and dust. Requires periodic calibration.
Photoelectric Any opaque/reflective object Long-range conveyor package counting, safety light curtains, sorting lines. Extremely long range (up to 50+ meters). High response rate. Small target detection. Lens lens contamination degrades performance. Highly susceptible to ambient light noise.

Numerical Problems: Sensor Interfacing & Motor Control

Problem 1: Inductive Sensor Interfaced with PMDC Conveyor Motor

Scenario: An inductive proximity sensor detects teeth on a steel gear mounted on a conveyor shaft driven by a PMDC Motor. The gear has $N = 30$ teeth. The sensor output feeds a digital tachometer counter. If the time interval between consecutive sensor pulses is $t = 2.5\text{ ms}$, calculate:

  1. The motor shaft speed in RPM ($N_m$).
  2. The line speed ($v$) of the conveyor belt if the motor drives a drum pulley of diameter $D = 0.2\text{ m}$.

Step-by-Step Solution:

1. Pulse Frequency ($f$):

f = 1 / t = 1 / (2.5 × 10⁻³ s) = 400 Hz

2. Motor Revolutions Per Second ($n$): Since 1 revolution yields 30 pulses from 30 teeth:

n = f / N = 400 / 30 = 13.333 rev/s

3. Shaft Speed in RPM ($N_m$):

N_m = n × 60 = 13.333 × 60 = 800 RPM

4. Conveyor Line Speed ($v$):

v = π × D × (N_m / 60) = π × 0.2 × 13.333 = 8.377 m/s

Problem 2: Photoelectric Sensor & BLDC Motor Automated Gate

Scenario: A BLDC motor drives an automated barrier gate operating at $N_m = 3000\text{ RPM}$ through a $GR = 50:1$ reduction gearbox. A retro-reflective photoelectric sensor acts as a safety stop edge. The gate arm length is $L = 3\text{ m}$. The sensor detects an obstacle and sends an emergency stop signal. The BLDC driver takes $t_r = 15\text{ ms}$ electronic response time and then decelerates at $\alpha = 120\text{ rad/s}^2$. Calculate the total linear arc distance traveled by the tip of the gate arm before stopping.

Step-by-Step Solution:

1. Gearbox Output Speed ($\omega_{out}$):

N_out = N_m / GR = 3000 / 50 = 60 RPM

ω_out = (2 × π × 60) / 60 = 6.283 rad/s

2. Angular Displacement during Response Time ($\theta_1$):

θ_1 = ω_out × t_r = 6.283 rad/s × 0.015 s = 0.0942 rad

3. Angular Displacement during Deceleration ($\theta_2$): Using $\omega_f^2 = \omega_i^2 - 2\alpha\theta_2$ where output deceleration $\alpha_{out} = \alpha / GR = 120 / 50 = 2.4\text{ rad/s}^2$:

0 = (6.283)² - 2 × 2.4 × θ_2 ==> θ_2 = 39.476 / 4.8 = 8.224 rad

4. Total Arc Distance at Gate Tip ($S_{total}$):

θ_total = θ_1 + θ_2 = 0.0942 + 8.224 = 8.318 rad

S_total = L × θ_total = 3 m × 8.318 rad = 24.954 meters

Problem 3: Capacitive Sensor Interfaced with 3-Phase Induction Motor Bottling Plant

Scenario: A 4-pole, $50\text{ Hz}$ Three-Phase AC Induction Motor drives a fluid packaging conveyor running at a slip $s = 4\%$. A capacitive proximity sensor monitors fluid volume inside plastic bottles. The sensor requires a minimum dwell time of $t_d = 20\text{ ms}$ over the $w = 5\text{ cm}$ target area of the bottle cap to make a valid dielectric measurement. Calculate:

  1. The actual motor shaft speed ($N_r$).
  2. The maximum allowable drive roller diameter ($D_{max}$) so that the conveyor speed does not cause sense errors.

Step-by-Step Solution:

1. Synchronous Speed ($N_s$) & Rotor Speed ($N_r$):

N_s = (120 × f) / P = (120 × 50) / 4 = 1500 RPM

N_r = N_s × (1 - s) = 1500 × (1 - 0.04) = 1440 RPM

2. Maximum Conveyor Linear Velocity ($v_{max}$):

v_max = Target Width / Dwell Time = (0.05 m) / (0.020 s) = 2.5 m/s

3. Maximum Roller Diameter ($D_{max}$):

v = π × D × (N_r / 60) ==> 2.5 = π × D_max × (1440 / 60)

D_max = 2.5 / (24 × π) = 0.0331 m = 33.16 mm

Problem 4: Inductive Home Indexing on a Stepper Motor Axis

Scenario: A 1.8° hybrid stepper motor drives a precision lead screw with pitch $p = 5\text{ mm/rev}$. An inductive sensor serves as the zero-position (HOME) limit switch. The motor operates in quarter-stepping mode ($1/4$ microstepping). If the controller searches for the home position at a velocity of $v = 15\text{ mm/s}$, determine:

  1. The step frequency (pulse rate in Hz) sent to the stepper driver.
  2. The positional resolution achieved per quarter-step pulse.

Step-by-Step Solution:

1. Full Steps Per Revolution:

Steps/rev = 360° / 1.8° = 200 full steps

2. Microsteps Per Revolution ($N_{micro}$):

N_micro = 200 × 4 = 800 microsteps/rev

3. Rotational Velocity ($n_{rev}$):

n_rev = Velocity / Pitch = (15 mm/s) / (5 mm/rev) = 3 rev/s

4. Pulse Frequency ($f_{pulse}$):

f_pulse = n_rev × N_micro = 3 × 800 = 2400 Hz (2.4 kHz)

5. Position Resolution ($Res$):

Res = Pitch / N_micro = (5 mm) / 800 = 0.00625 mm = 6.25 µm

Problem 5: Photoelectric Safety Sensor Interfaced with AC Servo Pick-and-Place

Scenario: An AC Servo Motor moves a high-speed pick-and-place robot arm carrying a payload. A through-beam photoelectric sensor curtain forms a safety boundary. The servo is traveling at full speed $V_0 = 2.0\text{ m/s}$. When an operator interrupts the beam, the sensor responds in $t_s = 2\text{ ms}$. The servo drive receives the signal, processes it in $t_d = 1\text{ ms}$, and applies maximum deceleration dynamic braking torque ($a = 25\text{ m/s}^2$). Compute the minimum safe mounting distance ($S_{safety}$) for the optical curtain away from the hazard zone.

Step-by-Step Solution:

1. Total Reaction Lag Time ($T_{reaction}$):

T_reaction = t_s + t_d = 0.002 s + 0.001 s = 0.003 s (3 ms)

2. Distance Traveled During Reaction Time ($S_1$):

S_1 = V_0 × T_reaction = 2.0 m/s × 0.003 s = 0.006 m (6 mm)

3. Distance Traveled During Dynamic Braking Deceleration ($S_2$):

V_f² = V_0² - 2 × a × S_2 ==> 0 = (2.0)² - 2(25) × S_2

S_2 = 4.0 / 50 = 0.08 m (80 mm)

4. Minimum Safety Separation Distance ($S_{safety}$):

S_safety = S_1 + S_2 = 0.006 m + 0.08 m = 0.086 m = 86 mm
